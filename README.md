# ✅ Task Manager (CRUD)

A task management app built in React using the Context API for state management, with a Material UI interface.

📦 **Repo:** https://github.com/Mohamed-Atwan/Crud2

---

## ✨ Features

- ➕ Full CRUD functionality (add, complete, filter tasks)
- 💾 Data persisted in localStorage across sessions
- 🗂️ Filter tabs to switch instantly between all, completed, and pending tasks

---

## 🧰 Tech Stack

- **React** – UI library
- **Context API** – State management
- **Material UI** – Component styling

---

## 🚀 Getting Started (Run Locally)

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mohamed-Atwan/Crud2.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd Crud2
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. Open your browser at the local address shown in the terminal (usually `http://localhost:5173`)
